How to read the network

Colours show observed service rules, not reachability or service health. Host grants are IP permissions, not active session tokens. Remaining lease is estimated at sample time. Counters reset when rules are replaced and do not count logins. Moving dots illustrate sampled activity batches, not individual captured packets. Green paths use actual source-specific allow-counter increases; red switch pulses use unattributed drop-counter increases. Cyan paths illustrate newly logged authentication events. Opening a page does not replay old live history. Short-lived rules can be missed between samples.
